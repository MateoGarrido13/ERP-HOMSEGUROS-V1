# ERP HOM Seguros

| Carpeta | Contenido | Deploy |
|---|---|---|
| `docs/` | Casos de uso, guías, templates, arquitectura | No aplica |
| `prototype/` | Mockup móvil del flujo PAS (Next.js) | Vercel/Netlify con *Root Directory* `prototype` |
| `front/` | App real (pendiente) | Root Directory `front` |
| `backend/` | API y servicios (pendiente) | Root Directory `backend` |

Cada carpeta es independiente: se instala, corre y despliega por separado.
